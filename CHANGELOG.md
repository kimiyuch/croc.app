# Changelog

## 0.3 (unreleased)

- **Updates.** Croc now looks for new versions once a day and offers to install them (Croc → Check for Updates…). That
  check is the only time it connects to the internet; turn it off with Croc → Check for Updates Automatically.
  Coming from 0.1 or 0.2, download this version by hand once; after that it updates itself.

## 0.2 (2026-10-19)

- A lighter green, like croc.kimiyu.ch: the icon's background and, in light mode, the band at the top of the window.
  The Convert button is green there so it still stands out. Dark mode looks the same as before.

## 0.1 (2026-10-19)

- **First release.** Drop MOV and MP4 files on Croc and get small copies for the web: Web MP4 (H.264), WebM (VP9)
  or a silent loop for background videos.
- Pick a size limit (720p to the original size) and a quality step. Portrait videos are handled the same as landscape
  ones, and nothing is ever made bigger.
- HDR videos from the iPhone are turned into normal colours, so they don't look grey in the browser.
- Each video shows its progress and how much smaller it got. Croc saves next to the original or in a folder you pick,
  never overwrites a file and never connects to the internet.
